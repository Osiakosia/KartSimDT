# KartSimDT Blender Toolkit

## Purpose

The Blender Toolkit provides engineering visualization and validation tools
for the KartSimDT Digital Twin project.

Blender is **not** the source of truth for track geometry.

The authoritative geometry is always generated by KartSimDT.

Blender is used for:

- Engineering visualization
- Geometry validation
- Reference data export
- Correction export
- Interactive inspection

```text

    addons/
        Blender Add-on source

    exporters/
        Export reference geometry
        Export correction sets
        Export engineering reports

    importers/
        Import KartSimDT geometry
        Import orthophotos
        Import telemetry

    validators/
        Geometry comparison
        Mesh comparison
        Engineering validation
```

---

## Engineering Workflow

```text
KartSimDT

↓

Generate Geometry

↓

Import into Blender

↓

Engineering Inspection

↓

Export Corrections

↓

KartSimDT
```

No manual Blender edits become permanent project data.

Only exported correction data is returned to KartSimDT.

---

## Source of Truth

KartSimDT remains the single authoritative source for:

- Track geometry
- Coordinate systems
- Engineering data
- Digital Twin representation

Blender stores temporary engineering visualization only.
